遊戲說明

保護 Lemon 的毛線不要被雨水打濕。遊戲開始後，觀察落下的雨滴並移動角色避開它們；想再玩一次時，選擇重新開始即可。

隱私權

Lemon’s Yarn 不需要帳號，沒有廣告或 App 內購買，也不會收集、儲存或分享個人資料。

Game Center 為選用功能，並由 Apple 依其隱私權條款提供。

支援

開啟客服表單。送出需要 GitHub 帳號，內容會公開；請勿提供個人資料、Apple ID 或 Game Center 帳號資料。

GitHub 服務受 GitHub 隱私權聲明約束。

English

How to play

Keep Lemon’s yarn dry in the rain. Watch for falling drops and move the character to avoid them; select restart whenever you would like to play again.

Privacy

Lemon’s Yarn does not require an account, contains no ads or in-app purchases, and does not collect, store, or share personal data.

Game Center is optional and is provided by Apple under Apple’s privacy terms.

Support

Open the support form. Submitting requires a GitHub account and the report will be public. Do not include personal information, Apple ID details, or Game Center account information.

GitHub is governed by the GitHub Privacy Statement.
