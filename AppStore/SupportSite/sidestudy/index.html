教材對照筆記，練習加深記憶

開始使用

  1. 在教材清單選「匯入教材」，從「檔案」選擇 PDF 或單張圖片。
  2. 開啟教材後選「編輯筆記」；在清楚標示的輸入區編寫，再選保存。取消會放棄該次未保存修改。
  3. 新增自己的題目、答案及來源頁碼；從來源連結回到教材核對。
  4. 離開前保存草稿。更新 App 請勿刪除重裝，以免遺失本機資料。

無法匯入時

確認檔案未加密、可由「檔案」開啟，且符合以下限制；重新選檔再試。需要協助時，請提供 App 版本、裝置與問題步驟，不必寄送私人教材或筆記。

PDF 最多 500 頁；JPEG／PNG／HEIC 單張圖片。每檔最多 50 MiB，圖片最多 4,000 萬像素。

对照学习簿 · 支持

教材对照笔记，练习加深记忆

开始使用

  1. 在教材列表选择“导入教材”，从“文件”选择 PDF 或单张图片。
  2. 打开教材后选择“编辑笔记”；在明确标示的输入区编写，再选择保存。取消会放弃此次未保存的修改。
  3. 添加自己的题目、答案和来源页码；通过来源链接返回教材核对。
  4. 离开前保存草稿。更新 App 时请勿删除重装，以免丢失本机数据。

无法导入时

确认文件未加密、可在“文件”中打开，并符合以下限制；重新选择文件再试。如需帮助，请提供 App 版本、设备和问题步骤，无需发送私人教材或笔记。

PDF 最多 500 页；JPEG／PNG／HEIC 单张图片。每个文件最多 50 MiB，图片最多 4,000 万像素。

SideStudy · Support

Read, Take Notes & Practice

Get started

  1. Choose Import material in the library, then select a PDF or a single image in Files.
  2. Open a material and choose Edit note. Write in the labeled editor, then save. Cancel discards that unsaved edit.
  3. Add your own questions, answers and source-page links. Return to the source to check your work.
  4. Save drafts before leaving. Do not delete and reinstall the app during an update: this can remove local work.

Import troubleshooting

Check that the file is unencrypted, opens in Files and meets the limits below, then select it again. For help, send the app version, device and reproduction steps. You do not need to send private study material or notes.

PDF: ≤500 pages · JPEG / PNG / HEIC · ≤50 MiB/file · ≤40 megapixels/image
