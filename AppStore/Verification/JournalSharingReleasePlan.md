# 日記分享：1.7.0 發布規劃

使用者已確認將日記分享功能納入預定的 1.7.0 版本。

## 繁體中文更新說明草稿（僅日記分享段落）

新增日記分享圖卡，提供貼文與直式兩種比例。iPhone／iPad 可儲存至照片、
複製文字，並透過系統分享選單分享至其他 App；macOS 可匯出 JPEG、
複製文字，並使用系統分享選單。

macOS 亦已加入與 iOS 一致的使用資格區塊及恢復購買入口。
正式更新說明仍需與 1.7.0 的其他已驗證變更整合，並完成各語系審閱。
