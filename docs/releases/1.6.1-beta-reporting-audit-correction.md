# 1.6.1 (13) App Store distribution entitlement audit correction

Date: 2026-09-11.

## Scope and diagnosis

The immutable exported app candidate remains source `4f98fe5d9af4a7f8d8623a227d1fe22ac7847cb5`.
The iOS, Watch and Share App Store exports and their embedded profiles all contain
`beta-reports-active` as the boolean `true`. The old exact entitlement allowlists
omitted this Apple distribution entitlement, so they rejected genuine exports.
Apple documents it in [QA1830](https://developer.apple.com/library/archive/qa/qa1830/_index.html).

This correction changes only the audit and its test fixtures. It does not change
app source, capabilities, binaries, profiles, signatures, release metadata or price.

## Contract

- Allow `beta-reports-active` only in the iOS, Watch and Share signed allowlists.
- Require the actual plist boolean `true` in both the profile and signature.
  Missing, false, string and integer values fail, independently on each side.
- Keep the macOS signed allowlist unchanged.
- Preserve all identifier, team, signing-certificate membership, expiry,
  distribution-profile, App Group, local-only/cloud/push and Mac sandbox checks.
