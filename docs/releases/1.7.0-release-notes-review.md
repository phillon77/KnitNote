## iPhone／iPad 更新說明

分享編織日記，留住作品的每一步。

- 新增日記分享圖卡，提供 4:5 貼文與 9:16 直式兩種比例。
- 分享前可調整文字與圖卡顯示內容，不影響原始日記。
- 可將圖卡儲存至照片、複製分享文字，或透過系統分享選單分享至其他 App。
