## 可重現命令

在固定來源副本執行：

```sh
xcodebuild archive -quiet -project KnitNote.xcodeproj -scheme KnitNote -configuration Release -destination 'generic/platform=iOS' -derivedDataPath /private/tmp/knitnote-170-signed.KbZ6qB/DerivedData -archivePath /private/tmp/knitnote-170-signed.KbZ6qB/KnitNote-iOS.xcarchive KNITNOTE_SOURCE_REVISION=0f679d96c0ff6935f249c2ad044fb88bbdc59934
xcodebuild -exportArchive -archivePath /private/tmp/knitnote-170-signed.KbZ6qB/KnitNote-iOS.xcarchive -exportPath /private/tmp/knitnote-170-signed.KbZ6qB/Distribution/iOS -exportOptionsPlist AppStore/Verification/ExportOptions-AppStore.plist
```

ExportOptions 指定 `destination=export`，且不自動修改版本與建置號。
