# KnitNote 1.3.1 Integration and Release-Gate Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one verifiable KnitNote 1.3.1 candidate containing the pattern-reader calculator, installed version/build display, and reusable YouTube pattern links without changing the already released 1.3.0 candidate or commercial configuration.

**Architecture:** Implement the three independently specified features through their own detailed TDD plans, integrate them on one 1.3.1 branch, then run combined persistence, backup, localization, cross-platform build, and physical-device gates. Treat the final commit/build/archive/App Store selection as one immutable candidate; no earlier spec, feature commit, or green test run counts as the submitted release.

**Tech Stack:** Swift 6, SwiftUI, Foundation Decimal, CryptoKit, LinkPresentation, Swift Testing, XCStrings, XcodeGen, iOS 18, macOS 15, watchOS companion regression.

## Global Constraints

- The 1.3.1 feature set is exactly: in-reader calculator, Settings About version/build row, and reusable YouTube pattern links.
- Detailed implementation authority comes from:
  - `docs/superpowers/plans/2026-08-04-pattern-reader-calculator.md`
  - `docs/superpowers/plans/2026-08-04-settings-about-version.md`
  - `docs/superpowers/plans/2026-08-04-youtube-pattern-links.md`
- Do not add embedded video, local video storage, categories/folders, calculator history, Watch calculator, a second About page, analytics, ads, subscriptions, or unrelated refactors.
- Keep current free-download, seven-day trial, and Lifetime Unlock commercial behavior unchanged during implementation.
- Keep Lifetime Unlock pricing unchanged during implementation and submission preparation.
- Defer App Store Small Business Program enrollment until after 1.3.1 is publicly available.
- Do not modify the released/approved 1.3.0 Build 6 worktree or retroactively claim a 1.3.0 archive includes these features.
- No version/build, merge, push, upload, submission, price, or enrollment action occurs without a later explicit user approval at that boundary.
