# KnitNote 1.4.0 Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship KnitNote 1.4.0 with complete Traditional Chinese, Simplified Chinese, English, German, French, and Japanese localization across iPhone, iPad, Mac, Apple Watch, Share Extension, accessibility, permissions, and App Store metadata.

**Architecture:** Extend the existing `AppLanguage`, `LanguageSelection`, `LanguageSettings`, and String Catalog architecture rather than adding a custom translation engine. Keep one authoritative supported-language list, inject the selected locale at each app surface, synchronize the selected locale to Apple Watch through the existing snapshot channel, and enforce completeness with catalog contract tests.

**Tech Stack:** Swift 6, SwiftUI, Foundation `Locale`, String Catalog (`.xcstrings`), Swift Testing, WatchConnectivity, Python 3 metadata validation, Xcode 26.

## Global Constraints

- 1.4.0 supports exactly `en`, `zh-Hant`, `zh-Hans`, `de`, `fr`, and `ja`.
- The user may follow the system language or choose a language inside KnitNote without restarting.
- Unsupported system languages and missing translations fall back to English; raw localization keys and blank UI are forbidden.
- User-created project, note, journal, yarn, counter, PDF, image, filename, and YouTube content must never be translated or mutated.
- Main app, Apple Watch, Share Extension, Info.plist, VoiceOver, and App Store metadata are all in scope.
- Simplified Chinese uses natural Mainland knitting terminology, not mechanical character conversion alone.
- No remote translation service, downloadable language pack, runtime machine translation, new analytics, or user-data format change.
- All implementation tasks use TDD and end in a focused commit.
- The submitted 1.3.1 candidate at `3ff06866923ee1d0952b211079e0e4fdd073867f` remains unchanged.

}
