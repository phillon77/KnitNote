# KnitNote 1.4.1 Localization and Completed-Project Protection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the proven KnitNote 1.4.0 localization system with Norwegian Bokmål, Swedish, Finnish, Danish, Korean, and Greek, and add completed-project deletion protection as a key 1.4.1 safety update.

**Architecture:** Reuse the centralized language list, shared picker, catalog contract harness, Watch snapshot locale field, terminology table, metadata validator, and release audit delivered by 1.4.0. Add six language cases and complete translations. Add deletion protection at both the project editor and persistence boundaries, then run one cross-platform acceptance matrix for the twelve-language candidate and the completed-project safety flow.

**Tech Stack:** Swift 6, SwiftUI, Foundation `Locale`, String Catalog (`.xcstrings`), Swift Testing, WatchConnectivity, Python 3 metadata validation, Xcode 26.

## Global Constraints

- 1.4.1 adds exactly Norwegian Bokmål `nb`, Swedish `sv`, Finnish `fi`, Danish `da`, Korean `ko`, and Greek `el`.
- The full supported set becomes `en`, `zh-Hant`, `zh-Hans`, `de`, `fr`, `ja`, `nb`, `sv`, `fi`, `da`, `ko`, and `el`.
- Norwegian uses Bokmål (`nb`), not the ambiguous legacy `no` code and not Nynorsk (`nn`).
- Greek uses modern Greek (`el`) without introducing a region-specific language case.
- 1.4.0 language behavior, fallback rules, user-data boundaries, Watch synchronization, and App Store truthfulness remain unchanged.
- No Icelandic, runtime machine translation, downloadable language pack, remote translation service, or data-format change.
- Completed projects cannot be deleted until the user restores them to in-progress status; in-progress project deletion remains available regardless of trial or purchase state.
- App Store What's New copy must identify completed-project deletion protection as a key 1.4.1 update alongside the six new interface languages.
- Every task uses TDD and ends in a focused commit.
- Implementation starts only after the released 1.4.0 source and exact release commit are available as the baseline.
