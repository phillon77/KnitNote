# 織圖後備作品封面設計

日期：2026-07-24  
狀態：已核准設計，等待規格審閱

## 目標

讓沒有自訂照片的作品自動顯示第一份織圖的第一頁，減少使用者建立作品後仍需另外選擇封面的步驟，同時保留現有的相機與相簿照片功能。

## 封面優先順序

作品封面依下列順序決定：

1. 使用者自行拍攝或從相簿選擇的作品照片。
2. 作品目前排序第一的織圖第一頁縮圖。
3. 現有的預設作品圖示。

加入織圖不得覆蓋使用者照片。使用者刪除自訂照片後，畫面立即回到織圖縮圖。第一份織圖被刪除後，改用下一份織圖；沒有織圖時才顯示預設圖示。

## 架構

### 封面解析

新增單一封面解析入口，供作品列表、作品詳情及其他作品照片顯示位置使用。解析入口接收作品資料，先查詢現有的自訂照片 URL；不存在時，再查詢第一份織圖的縮圖 URL。

畫面不自行判斷檔案位置，也不在各 View 重複實作優先順序。這可確保 iPhone、iPad 與 Mac 的行為一致。

### 織圖縮圖服務

新增獨立的織圖縮圖服務：

- PDF：渲染第一頁。
- PNG、JPEG、HEIC：讀取原圖並校正方向。
- 將長邊限制在適合作品卡片與詳情頁的尺寸。
- 輸出 JPEG 快取，使用與現有作品照片相近的壓縮品質。
- 以 project ID 與 pattern ID 建立穩定且不衝突的快取檔名。

縮圖屬於衍生資料，不寫入 `StoredProject.photoFilename`，也不納入備份。備份還原成功後清除既有縮圖快取，再從還原後的原始織圖重新產生，避免沿用還原前的舊畫面。

### 產生時機

第一份織圖成功匯入並保存後，在背景建立縮圖。顯示封面時若快取不存在，也可按需重建，因此產生縮圖失敗不會讓織圖匯入失敗。

刪除織圖時一併清除該織圖的縮圖快取。刪除第一份織圖後，封面解析入口會自然改用下一份織圖，不需修改作品資料。

## 使用者操作

- 現有的相機、相簿選擇、更換與刪除照片操作保持不變。
- 使用者新增自訂照片後，立即顯示自訂照片。
- 使用者刪除自訂照片後，立即顯示第一份織圖縮圖。
- 不新增設定、提示視窗或封面管理畫面。

## 錯誤處理

- 無法解碼織圖或產生縮圖時，顯示預設作品圖示。
- 縮圖錯誤不阻止織圖匯入、閱讀或刪除。
- 後續再次顯示封面時允許重試產生快取。
- 快取清理失敗不影響作品或織圖資料的保存。

## 資料與備份

- 不調整 `ProjectArchive` 版本。
- 不新增持久化的封面來源欄位。
- 自訂作品照片仍照現有方式備份與還原。
- 織圖縮圖不納入備份，還原後由原始織圖重建。
- 此功能不會因縮圖而持續增加備份檔案大小。

## 測試

測試先行涵蓋：

1. 有自訂照片時永遠選擇自訂照片。
2. 沒有自訂照片時選擇第一份織圖縮圖。
3. 刪除自訂照片後回到織圖縮圖。
4. 刪除第一份織圖後改用下一份織圖。
5. 沒有照片與織圖時使用預設圖示。
6. PDF 第一頁與圖片織圖均可建立有效縮圖。
7. 縮圖產生失敗不回滾已成功匯入的織圖，封面安全退回預設圖示。
8. 縮圖快取不進入備份清單，且可在還原後重建。

## 不包含

- 手動選擇任意一份織圖作為封面。
- 選擇 PDF 的其他頁面作為封面。
- 編輯、裁切或套用濾鏡。
- 改變織圖排序介面。
