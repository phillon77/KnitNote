# KnitNote 1.3 毛線工作流設計

日期：2026-07-29
狀態：已確認設計；2026-07-31 納入 Mac 版 P0 畫面修正

## 目標

KnitNote 1.3 先修復 Mac 版設定與新增作品畫面的可用性，再完成一個產品主題：讓使用者清楚記錄每件作品使用的毛線，並以相機、相簿或 Mac 檔案中的毛線標籤快速建立可靠、可人工確認的毛線資料。

本版本不記錄作品實際使用幾球或幾克，不自動扣除庫存，不查詢網路商品資料庫，也不使用生成式 AI 猜測標籤內容。

## 開發與發布策略

1. P0 先修正 Mac 版設定與新增作品畫面，並完成獨立驗收。
2. 里程碑一完成作品與毛線的雙向連結。
3. 里程碑二完成最多兩張標籤照片、裝置端 OCR、候選欄位與確認流程。
4. 各階段可分開開發與驗收，但只有全部通過後才建立唯一的 1.3 送審候選版本。
5. 同一版本只接受必要的錯誤修正，不加入其他大型功能。

## Mac 版 P0 畫面修正

目前 Mac 版有兩個已觀察到、會直接影響基本操作的問題：

- 設定畫面的內容擠在左側，上方與右側留白過多。
- 新增作品視窗太窄，左側標籤被截斷，輸入欄位與照片按鈕排列不整齊。

修正規格如下：

- 設定內容在視窗中水平置中，左右至少保留 24 pt 安全間距，內容最大寬度為 720 pt。
- 新增作品視窗最小寬度為 520 pt、理想寬度為 620 pt、最小高度為 560 pt。
- 照片操作在寬度足夠時維持水平排列；不足時自動改為垂直排列，不截字也不互相覆蓋。
- iPhone 與 iPad 現有版面與操作不得因此改變。
- 使用繁體中文與英文，分別在最小、預設與放大視窗驗收；同時檢查鍵盤導覽、焦點順序與 VoiceOver。

## 作品中的使用毛線

作品詳情維持以下主要順序：

`照片 → 織圖 → 筆記 → 計數器 → 使用毛線 → 日記`

「使用毛線」區塊遵循以下行為：

- 沒有連結時，只顯示一個簡潔的「加入使用毛線」操作。
- 一件作品可連結零款、一款或多款毛線。
- 每款毛線顯示小照片、品牌／系列、顏色與色號；缺少的欄位不顯示空白佔位。
- 點選毛線可開啟毛線詳情。
- 編織中的作品可新增或解除毛線連結。
- 完成作品保留歷史使用毛線，但不能新增或解除連結。
- 解除連結只移除作品與毛線的關係，不刪除作品、毛線或照片。
- 毛線詳情或編輯頁也能選擇其連結的作品。
- 1.3 只記錄使用了哪些毛線，不記錄實際用量。

現有 `StoredYarn.linkedProjectIDs` 是唯一關係來源。作品頁以反向查詢取得使用毛線，不在作品模型新增另一份 `yarnIDs`，避免兩份關係失去一致性。

刪除作品時，Store 從所有毛線移除該作品識別碼。刪除毛線不影響作品。所有連結變更由 Store 驗證識別碼、作品完成狀態、試用或購買權益，並以單次持久化交易完成。

## 毛線標籤掃描

### 入口

新增毛線與編輯既有毛線都提供「掃描標籤」：

- iPhone／iPad 可直接開啟相機或從相簿選擇。
- Mac 可從照片或 Finder 選擇 JPEG、PNG 或 HEIC 圖片；沒有相機時不顯示相機操作。
- Finder 選取的檔案以 security-scoped access 暫時讀取，立即複製到 App 管理的暫存區，完成後停止存取；不保存外部路徑或 bookmark。
- 每款毛線最多保存兩張標籤照片，適合正面與背面。
- 第一張完成後可選擇「掃描另一面」，但不能加入第三張。

### 流程

掃描流程保持三個階段：

1. 選擇或拍攝一至兩張照片。
2. 在裝置端辨識並整理候選值。
3. 在一般毛線編輯畫面確認、修改、清除後按「完成」。

掃描與辨識不直接建立或修改正式毛線。只有使用者按下「完成」後，文字資料與最佳化照片才一起保存。取消流程不得改動既有毛線，也不得留下暫存檔。

### 欄位

首版辨識以下資料：

- 品牌
- 系列
- 顏色
- 色號
- 染缸號
- 每球重量
- 每球長度
- 材質與比例
- 建議棒針尺寸
- 建議鉤針尺寸

數值保存使用明確基準單位，介面依所在地區顯示公制或英制。原始候選文字只存在於未保存的掃描草稿中，除非使用者確認為正式欄位。

### OCR 與候選規則

- 使用 Apple 裝置端 Vision 文字辨識，不把照片或文字上傳至開發者或第三方服務。
- iOS 與 macOS 共用同一個 App target Vision adapter；執行時先查詢裝置支援的辨識語言，優先使用 `zh-Hant` 與 `en-US`，不支援時安全退回可用語言。
- 純邏輯解析器依標題、單位、鄰近位置與辨識信心產生欄位候選。
- 高信心且無衝突的候選可預先填入，但仍需使用者按「完成」。
- 低信心候選顯示「待確認」，可修改、清空或接受。
- 兩張照片產生不同候選時，不自動覆蓋；列出候選供使用者選擇。
- 辨識不到文字時保留照片並開啟空白編輯欄位。
- 不使用條碼網路查詢、品牌資料庫或生成式 AI 補造缺失內容。

## 標籤照片與容量

- 標籤照片與毛線展示照片分開保存。
- App 不保存相機或相簿中的原始大圖。
- 正式標籤照片保存為移除不必要中繼資料的最佳化 JPEG。
- 最長邊約 1600 px，以標籤文字仍可閱讀為準。
- 每張以約 150–400 KB 為設計目標；最多兩張。
- 毛線資料只保存受管理的照片檔名，不把影像資料嵌入 JSON。
- 使用者可查看、替換或刪除任一標籤照片；刪除照片不清除已確認文字。
- 更換照片、刪除毛線、取消或保存失敗時，檔案服務清除不再被參照的暫存或正式檔案。
- 設定頁顯示毛線標籤照片的總使用空間。

照片處理與 OCR 在背景執行，不阻塞主執行緒。檔案安裝採暫存、驗證及原子替換，避免 JSON 已更新但照片尚未完成的半套狀態。

## 資料格式與備份

`StoredYarn` 新增可選的結構化標籤欄位與最多兩個標籤照片檔名。舊資料解碼時所有新欄位預設为 `nil` 或空集合，不要求使用者手動遷移。

完整備份包含：

- 已確認的結構化毛線欄位
- 正式標籤照片
- 既有 `linkedProjectIDs`

還原時驗證照片格式、大小、檔名安全與參照完整性。舊版備份仍可還原；照片損壞或遺失時保留毛線文字資料，不能使整個毛線庫或備份失敗。

試用與 StoreKit 購買資格不納入手動備份。還原資料不能重設試用、永久解鎖 App 或把已解鎖使用者降級。

## 架構邊界

- `ProjectYarnQuery` 或 Store 查詢：依 `linkedProjectIDs` 反查作品使用毛線。
- `ProjectYarnSection`：顯示作品的毛線摘要與連結入口。
- `ChooseProjectYarnsView`：選擇、建立及解除作品毛線連結。
- `YarnLabelRecognitionService`：將一至兩張圖片轉為文字觀察值。
- `YarnLabelImagePicker`：統一 iOS 相機／相簿與 Mac 照片／Finder 的圖片輸入邊界。
- `YarnLabelFieldParser`：純邏輯解析欄位候選、信心與衝突。
- `YarnLabelScanSession`：管理照片、辨識中、候選、使用者確認與取消狀態。
- `YarnLabelPhotoFileService`：正規化、壓縮、原子安裝、替換及清理標籤照片。
- `JSONProjectStore`：唯一負責正式毛線資料、關係與檔案持久化交易。

Vision、相機、照片選擇與檔案 I/O 都位於服務邊界；SwiftUI 畫面只顯示狀態並傳送使用者意圖。核心解析器不依賴 Vision 或 SwiftUI，以便使用固定文字樣本完整測試。

## 畫面、錯誤處理與輔助使用

- 沿用白色圓角卡片、莓紅色重點色與目前的水彩視覺系統。
- 不增加獨立掃描管理頁或資料夾分類。
- 待確認與衝突狀態同時顯示文字或圖示，不能只靠顏色。
- 相機權限被拒絕時提供「前往設定」及「改從相簿選擇」。
- 圖片無效時不建立毛線，允許重新選擇。
- OCR 無文字或部分失敗時仍可手動填寫。
- 最終保存失敗時保留畫面草稿供重試，但不發布半完成資料。
- Traditional Chinese 與 English 必須同時完成。
- VoiceOver 讀出毛線名稱、品牌、顏色、連結狀態、照片序號與待確認狀態。
- 動態字級放大時，毛線區塊與候選欄位改為垂直展開，不截斷關鍵資料。
- Mac 掃描與編輯 sheet 可調整大小；寬視窗使用左右並排，窄視窗自動改成垂直配置。
- Mac 的 Return 執行目前可用的主要操作，Escape 取消未保存流程；焦點順序必須與視覺順序一致。

## 驗收

### P0：Mac 基本畫面

- 設定內容在最小、預設與放大視窗中維持置中，不貼左也不產生不合理的大面積空白。
- 新增作品在 520 pt 最小寬度仍可完整顯示標籤、欄位與照片操作。
- 照片操作會依可用寬度在水平與垂直配置間切換。
- 繁體中文與英文都不截字，鍵盤、焦點與 VoiceOver 操作正常。
- iPhone 與 iPad 的設定與新增作品畫面沒有回歸。

### 里程碑一：毛線連結

- 從作品頁連結與解除多款毛線。
- 從毛線頁連結與解除多個作品。
- 兩個入口即時顯示相同關係。
- 重開 App 後連結仍存在。
- 解除連結不刪除作品、毛線或照片。
- 完成作品保留唯讀歷史並拒絕修改。
- 備份、還原及舊資料遷移保持關係。

### 里程碑二：標籤掃描

- 相機與相簿都可選擇一至兩張照片。
- Mac 可從照片與 Finder 選擇 JPEG、PNG、HEIC；取消、無法存取、雲端檔尚未下載與不支援格式都有可恢復的錯誤狀態。
- 測試繁體中文、英文、混合標籤、公制、英制、材質比例、針號範圍及小數逗號。
- 低信心與衝突候選必須由使用者確認。
- 測試取消、權限拒絕、無文字、損壞圖片、第三張圖片、保存失敗及檔案回滾。
- 刪除照片後文字仍存在。
- 備份還原後文字、照片與連結仍可使用。
- 容量統計與孤立照片清理正確。

### 1.3 正式發布門檻

- 鎖定唯一 commit、版本與 Build。
- 確認真實 Git 倉庫、預定分支、乾淨工作區及 GitHub 同步。
- 使用確切候選 Build 在實體 iPhone、iPad 與 Mac 驗收；Mac 必須包含 P0 視窗尺寸、Finder 匯入、裝置端 OCR 與備份還原。
- 重新驗證 7 天試用、永久解鎖、舊付費使用者、StoreKit 暫時離線、Apple Watch 與 Share Extension。
- 自動測試與四平台 Release Build 是必要條件，但不能取代實體／TestFlight 驗收。
- 送審前核對 binary、App 價格、IAP、metadata、截圖與審核說明屬於同一候選版本。
- 送審後立即記錄 archive、commit SHA、版本、Build、App Store Connect build、IAP、價格及 submission ID。
- 推送並標記送審原始碼，使審核中的 binary 可重建。
- 任一候選版本、Git、裝置、IAP、定價或 metadata 狀態不確定時停止送審。

## 不在 1.3 範圍

- 作品毛線實際使用量
- 自動扣除毛線庫存
- 條碼或第三方毛線商品資料庫
- 生成式 AI 補寫標籤內容
- 雲端帳號或開發者伺服器
- 毛線分類或自訂資料夾
- Watch 掃描或管理毛線
- 訂閱、廣告或分析追蹤
- 與本主題無關的大型功能
