# Mac 設定頁簡化設計

## 目的

將 macOS 設定頁從緊密、難以掃讀的 `Form` 排列，改成清楚的單欄分類卡片。所有設定仍保留在同一頁，使用者不需要切換側邊分類。

## 範圍

- 僅重新排列 macOS 的 `SettingsView`。
- iPhone 與 iPad 繼續使用現有 `Form`，外觀與操作不變。
- 不新增、刪除或改變任何設定功能。
- 不改變語言選擇、計算工具、儲存空間讀取、備份／還原或版本資訊的資料流程。

## macOS 版面

macOS 使用可捲動、置中的單欄內容，依序顯示四個分類卡片：

1. **一般**：語言。
2. **編織工具**：密度計算、等距加針／減針。
3. **資料**：毛線標籤照片容量、完整備份、從備份還原、上次成功備份。
4. **關於**：版本與 Build。

版面規則：

- 內容最大寬度 560 點，置中顯示。
- 四周保留 28 點間距；分類卡片之間保留一致間距。
- 每個卡片使用水彩主題表面、圓角與低對比邊界。
- 分類標題使用莓紅色；功能列使用一致的最小列高、圖示、文字與右側數值／箭頭。
- 語言選擇顯示在「一般」列的右側。
- 計算工具與備份操作以標準導覽／操作列呈現，不再使用橫跨整個內容的巨大按鈕。
- 容量、上次備份時間、版本與 Build 對齊在列的右側。
- 視窗較矮時可垂直捲動，內容不截斷。
- 保留現有水彩背景、莓紅色操作色與無障礙資訊。

## 元件界線

- `SettingsView` 只負責平台選擇與分類排列。
- macOS 分類卡片拆成小型私有 View，分別承載一般、工具、資料與關於內容。
- 現有 `BackupSettingsSection` 與 `YarnLabelStorageRow` 的行為繼續共用；如需配合卡片排列，只增加可重用的 macOS 呈現方式，不複製備份或容量計算邏輯。

## 測試與驗收

自動測試：

- 更新 macOS 設定版面契約測試，確認使用 `ScrollView`、單欄內容與 560 點最大寬度。
- 確認 macOS 分支不再直接使用完整 `Form` 排列。
- 確認四個分類及其功能仍存在，順序正確。
- 確認非 macOS 分支仍使用現有 `settingsForm`。
- 執行語言、計算工具、容量、備份／還原與版本資訊既有測試。

人工驗收：

- 在一般 Mac 視窗與較小視窗檢查四個分類都清楚、沒有裁切或擠壓。
- 確認語言可以切換，兩個計算工具可以開啟。
- 確認容量資訊、備份、還原與上次備份時間正常。
- 確認版本與 Build 顯示正確。
- 分別以繁體中文、英文及深色模式檢查對齊與可讀性。
- 確認 VoiceOver 的閱讀順序依畫面由上而下。

## 不在本次範圍

- 新增設定搜尋或左右分類導覽。
- 改變任何設定值或備份檔案格式。
- iPhone、iPad 設定頁重新設計。
