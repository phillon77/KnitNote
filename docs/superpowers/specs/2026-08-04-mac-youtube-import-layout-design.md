# Mac YouTube 新增視窗版面設計

## 目的

修正 macOS「從 YouTube 連結新增」視窗過小、表單貼邊且內容被擠壓的問題，讓網址、影片資料、縮圖與標題欄位保持清楚、完整且容易操作。

## 範圍

- YouTube 新增視窗僅調整 macOS 的 `AddYouTubePatternView` 版面。
- 織圖庫列表與作品內織圖列表的 YouTube 縮圖在所有支援平台套用同一個較小的 16:9 尺寸規則。
- iPhone 與 iPad 繼續使用現有 `Form` 版面，不改變外觀或操作流程。
- 不改變 YouTube 網址驗證、資料讀取、縮圖快取、織圖建立、作品連結或錯誤處理邏輯。
- 不下載或保存 YouTube 影片；仍只保存連結、標題與縮圖快取。

## macOS 版面

macOS 使用單欄、可捲動的內容區，取代目前直接顯示的 `Form`。

由上而下排列：

1. YouTube 連結標題。
2. 網址輸入欄。
3. 讀取影片資料按鈕。
4. 影片資料標題。
5. 16:9 縮圖預覽。
6. 影片標題輸入欄。
7. 載入狀態、手動輸入提示或錯誤訊息。

內容規則：

- 視窗最小寬度 520 點、理想寬度 620 點。
- 視窗最小高度 520 點；內容超出時可以捲動。
- 單欄內容置中，最大寬度 560 點，四周保留 28 點間距。
- 縮圖維持 16:9，最大寬度 320 點，不因視窗放大而無限制變大。
- 尚未取得縮圖時，使用現有播放圖示作為固定尺寸的預設預覽。
- 取消與新增仍位於視窗工具列；新增按鈕的啟用條件不變。
- 保留目前水彩背景、莓紅色操作色與無障礙標籤。

## 列表縮圖

- 織圖庫列表與作品內織圖列表的 YouTube 縮圖都改為 16:9。
- YouTube 縮圖使用 76×43 點，避免目前 76×96 點的直式裁切讓影片縮圖顯得過大。
- YouTube 列表列高隨縮圖縮小，不保留不必要的 96 點最小高度。
- PDF 與照片織圖維持現有 76×96 點縮圖與列高，不受影響。

## 狀態與錯誤

- 讀取影片資料時，在內容區顯示進度與載入文字。
- 無法讀取資料時，保留手動輸入標題的提示。
- 新增失敗時，在內容區以紅色文字顯示既有錯誤訊息。
- 關閉視窗時繼續取消尚未完成的資料請求。

## 測試與驗收

自動測試：

- 加入 macOS 版面契約測試，確認使用 `ScrollView` 與單欄內容，而不是 `Form`。
- 確認 macOS 最小／理想尺寸、內容最大寬度與縮圖 16:9 限制存在。
- 確認兩個列表的 YouTube 縮圖都使用 76×43 點，而 PDF／照片仍使用 76×96 點。
- 確認非 macOS 分支仍保留 `Form`。
- 執行既有 YouTube 新增、縮圖、連結與本地化測試。

人工驗收：

- 在 Mac 從織圖庫與作品內分別開啟「從 YouTube 連結新增」。
- 確認視窗不再被壓成狹小表格，左右不貼邊，所有欄位與按鈕完整可見。
- 確認視窗縮至最小尺寸時仍可捲動並完成新增。
- 確認成功讀取影片資料後，縮圖比例正確且不過大。
- 確認織圖庫與作品內的 YouTube 縮圖均較小、完整呈現 16:9，沒有直式放大或裁切。
- 確認英文與繁體中文文字均不截斷。
- 確認 iPhone 與 iPad 的既有新增流程沒有變化。

## 不在本次範圍

- Mac 設定頁重新排版。
- YouTube 播放器內嵌、影片下載或離線播放。
- YouTube 資料模型或作品連結規則變更。
