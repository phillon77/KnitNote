# KnitNote 1.3.1 設定頁版本資訊設計

日期：2026-08-04  
狀態：書面規格已審閱核准，實作計畫已完成

## 目標

在設定頁提供容易找到的已安裝版本資訊，讓使用者與開發者可立即確認目前執行的是哪個 App Store、TestFlight 或 Xcode Build，不必離開 App 或前往系統設定查找。

本功能納入 KnitNote 1.3.1，支援 iPhone、iPad 與 Mac。

## 已確認產品決策

- 在設定頁最下方新增「關於」區塊。
- 區塊內直接顯示版本與 Build，不建立第二層「關於」頁面。
- 左側標題為「版本」，右側顯示如 `1.3.1（Build 7）` 的實際安裝資訊。
- 內容只供閱讀，不可點擊，也不加入複製、網站、隱私權或開發者資訊。
- 顯示值必須從目前 App bundle 讀取，不得硬編碼。
- 繁體中文與英文同步支援。

## 畫面與排列

在現有 `SettingsView` 的備份區塊之後新增最後一個 `Section`：

- 區塊標題：`關於`／`About`。
- 單一資訊列左側：`版本`／`Version`。
- 單一資訊列右側：實際版本與 Build。

中文顯示格式：

`1.3.1（Build 7）`

英文顯示格式：

`1.3.1 (Build 7)`

右側值採次要文字樣式並允許縮放或換行，避免大字級、窄螢幕或較長 Build 字串被截斷。整列不顯示 chevron，也不使用按鈕或導覽連結語意。

## 資料來源與格式化

建立一個小型、可測試的版本資訊值型別或提供者，負責從注入的 bundle 資訊字典取得：

- `CFBundleShortVersionString`：使用者可見版本，例如 `1.3.1`。
- `CFBundleVersion`：Build 編號，例如 `7`。

格式化規則：

1. 兩個值都存在且去除首尾空白後非空，顯示完整的版本與 Build。
2. 任一值缺失、型別錯誤或為空字串時，該列顯示 `—`。
3. 不從 Xcode 專案檔、`MARKETING_VERSION` 字面值或程式常數推測版本。
4. 顯示格式由目前語系決定，但原始版本與 Build 字串不做數值轉換，避免改寫 Apple 提供的內容。

版本資訊只在畫面建立時讀取，不需要保存、不寫入 `JSONProjectStore`、UserDefaults 或備份。

## 多平台與輔助使用

- iPhone、iPad 與 Mac 使用相同的 `SettingsView` 區塊和資料來源。
- 「關於」、「版本」與格式字串提供繁體中文及英文翻譯。
- VoiceOver 依序讀出「版本，1.3.1，Build 7」，整列為靜態文字，不宣告為按鈕。
- 動態字級放大時保留完整內容；必要時右側值可換行並維持尾端對齊。
- 鍵盤焦點不需要停在此資訊列，因為它沒有操作行為。

## 錯誤與降級行為

- bundle 缺少任一必要欄位時顯示 `—`，不顯示 `Unknown`、空白或內部錯誤訊息。
- 讀取失敗不得影響設定頁其他功能，包括語言、編織計算工具、毛線標籤容量與備份還原。
- 顯示內容不使用目前規格文件中的範例版號作為後備值。

## 測試策略

### 單元測試

- 正常字典產生完整的版本與 Build 顯示資料。
- 缺少版本、缺少 Build、錯誤型別、空白字串時回傳不可用狀態。
- 版本與 Build 保留原始非空字串，不被數值轉換。
- 中文與英文格式分別使用全形與半形括號。

### 畫面與契約測試

- `SettingsView` 最後包含「關於」區塊與版本資訊列。
- 畫面使用 bundle 版本提供者，不含硬編碼的 `1.3.1` 或 Build 編號。
- 資訊列不是 `NavigationLink` 或可點擊按鈕。
- 繁體中文與英文鍵值完整。
- Mac 既有設定頁寬度與表單排列契約不受影響。

### 實機驗收

使用同一個 1.3.1 候選 Build 驗收：

1. 從 Xcode 安裝至 iPhone，確認設定頁顯示與 Xcode General／archive 相同的版本與 Build。
2. iPad 確認直向、橫向與大字級下完整可讀。
3. Mac 確認設定頁最下方顯示相同候選版本與 Build，且表單沒有被裁切。
4. 開啟 VoiceOver，確認讀出版本與 Build，且不誤報為可點擊控制。
5. 候選 Build 安裝完成後，三平台顯示值必須完全一致；任一平台不同即停止送審。

## 版本與發佈邊界

- 本功能屬於 KnitNote 1.3.1，不修改已通過審查的 1.3.0 Build 6。
- 規格核准後與織圖內建計算機一起納入 1.3.1 實作計畫。
- 完成程式與自動測試不等於可送審；必須以唯一候選 commit 驗證 iPhone、iPad 與 Mac 顯示相同版本與 Build。
- 本規格不授權修改版本號、Build、合併、推送、上傳或送審。
