# KnitNote 1.4.1 已完成作品刪除保護設計

## 目標

避免使用者誤刪已完成的編織作品，同時保留進行中作品目前簡單的刪除流程。

這是 KnitNote 1.4.1 的重點功能更新，並必須出現在發佈說明與實機驗收清單。

## 使用者體驗

- 進行中的作品：編輯頁的「刪除」按鈕可使用，按下後仍需第二次確認。
- 已完成的作品：編輯頁的「刪除」按鈕顯示為停用狀態，不能按下。
- 停用的刪除按鈕下方顯示：「請先恢復為進行中，才能刪除作品。」
- 同一頁保留現有「恢復編織」操作。恢復後，使用者再進入編輯頁即可刪除。

## 規則

- 介面必須先阻止已完成作品的刪除操作。
- 資料儲存層也必須拒絕直接刪除已完成作品，避免未來其他畫面或同步入口繞過介面保護。
- 「恢復為進行中」後，就能沿用現有刪除流程。
- 此保護與試用期或購買狀態無關；進行中作品仍可隨時刪除。

## 錯誤處理

- 若作品狀態在確認刪除前變為已完成，儲存層拒絕刪除，作品與關聯資料保持不變。
- 其他儲存失敗沿用現有錯誤提示，不隱藏失敗。

## 驗證

- 單元測試：已完成作品的刪除不會改變封存或關聯資料。
- 單元測試：恢復為進行中後可正常刪除。
- 介面測試：已完成時刪除按鈕停用且提示文字出現；進行中時刪除按鈕可使用。
- iPhone 實機驗收：測試進行中刪除、已完成阻擋、恢復後刪除三條路徑。
