# KnitNote 1.5.0 Release Notes Design

Date: 2026-08-10

## Goal

Prepare truthful, consistent App Store `What's New` copy for KnitNote 1.5.0
across all thirteen supported metadata locales, without changing any other
store field or release state.

## Approved message

Every locale communicates the same six implemented updates:

- counter reminders;
- direct counter-value entry;
- an improved iPad counter layout;
- Apple Watch coordination;
- complete Dutch interface support; and
- a Projects title that follows the language selected inside KnitNote.

Traditional Chinese source meaning:

> KnitNote 1.5.0 新增計數器提醒與數值直接輸入，並改善 iPad 計數器版面及
> Apple Watch 協作。現在也完整支援荷蘭文，「作品」標題會依照所選 App 語言顯示。

English source meaning:

> KnitNote 1.5.0 adds counter reminders and direct value entry, with an
> improved iPad counter layout and Apple Watch coordination. Dutch is now
> fully supported, and the Projects title follows your selected app language.

Each translation may use natural sentence order and platform terminology, but
must preserve all six claims and must not add background notifications, cloud
sync, automatic pattern translation, deleted-project recovery, subscription,
trial, price, purchase, publication, or physical-acceptance claims.

## Scope

Modify only the `What's New` field in these thirteen metadata packages:

- `zh-Hant.md`
- `en-US.md`
- `de-DE.md`
- `fr-FR.md`
- `ja-JP.md`
- `zh-Hans.md`
- `nb-NO.md`
- `sv-SE.md`
- `fi-FI.md`
- `da-DK.md`
- `ko-KR.md`
- `el-GR.md`
- `nl-NL.md`

The existing Dutch copy is updated only if needed to carry the same six-claim
message. Name, subtitle, promotional text, keywords, description, and all URLs
remain byte-for-byte unchanged.

## Validation

Add metadata tests that fail when any locale:

- omits the exact release identity `1.5.0`;
- retains `1.4.1` in `What's New`;
- omits any of the six approved concepts; or
- exceeds Apple's existing field limits or triggers a prohibited-claim guard.

The concept contract is locale-aware and uses reviewed representative terms;
it does not require word-for-word translations. Tests are written and observed
failing before metadata changes.

After the RED-to-GREEN cycle, run the complete metadata unit suite, production
metadata checker, static release audit, full Swift suite, and diff validation.
Metadata-only changes do not require rebuilding unchanged binaries.

## Release boundary

This work prepares repository metadata only. It does not create an archive or
Release Candidate, sign or export a product, mutate App Store Connect, upload,
select a build, submit for review, merge, or push. Those remain separate,
explicitly authorized gates after this metadata package passes review.
