# KnitNote 1.5.1 Release Notes Design

Date: 2026-08-15

## Goal

Prepare truthful, natural App Store `What's New` copy for KnitNote 1.5.1 in
all thirteen supported metadata locales, then use the reviewed copy for both
the iOS and macOS 1.5.1 version pages without changing other store copy.

## Approved message and style

Use three short, direct claims in this order:

1. the pattern library supports user-created folders;
2. the Yarn Library title immediately follows the language selected inside
   KnitNote; and
3. KnitNote offers an App Store reminder when a newer public version is
   available.

Traditional Chinese source meaning:

> KnitNote 1.5.1 現在支援自訂資料夾整理織圖。毛線庫標題會立即跟隨所選
> App 語言；有新版本可用時，也會提供前往 App Store 的提醒。

English source meaning:

> KnitNote 1.5.1 now lets you organize patterns in custom folders. The Yarn
> Library title immediately follows your selected app language, and KnitNote
> lets you know when a newer version is available on the App Store.

Each translation may use natural local sentence order and established KnitNote
terminology, but it must preserve all three claims. `KnitNote`, `App Store`,
and version `1.5.1` remain exact product terms where customary.

## Claim boundaries

The copy must not claim background or push notifications, automatic or forced
updates, automatic downloads, cloud sync, account-based delivery, automatic
pattern classification, nested folders, cross-folder membership, translation
of user content, subscription, price, publication, approval, or physical
acceptance. The reminder is an in-app route to the App Store, not a system
notification or an updater.

## Scope

Modify only the `What's New` field in these thirteen metadata packages:

- `zh-Hant.md`
- `en-US.md`
- `de-DE.md`
- `fr-FR.md`
- `ja-JP.md`
- `zh-Hans.md`
- `nb-NO.md`
- `sv-SE.md`
- `fi-FI.md`
- `da-DK.md`
- `ko-KR.md`
- `el-GR.md`
- `nl-NL.md`

Name, subtitle, promotional text, keywords, description, URLs, screenshots,
privacy answers, pricing, and existing user-created content remain unchanged.
The same reviewed localized notes are used on iOS and macOS.

## Validation and review

Tests must fail when any locale:

- omits exact release identity `1.5.1`;
- retains the 1.5.0 release-note message;
- omits folders, the reactive Yarn Library title, or the newer-version App
  Store reminder;
- introduces a prohibited claim;
- is blank, key-valued, copied from English where English is not the locale, or
  exceeds Apple's field limit; or
- changes a metadata field outside `What's New`.

Translations receive a complete thirteen-locale structural/token review and an
independent linguistic review, with special attention to Traditional Chinese,
Japanese, Korean, and Simplified Chinese. Metadata tests, the production
metadata checker, static release audit, and diff validation must pass before
any App Store Connect text is saved. Metadata-only changes do not require a
new binary build.

## App Store Connect flow

After the repository metadata is reviewed and committed:

1. create iOS and macOS version 1.5.1 pages;
2. preserve carried-forward screenshots and unchanged metadata;
3. enter the reviewed `What's New` value in all thirteen locales on both
   platforms;
4. select the already processed Build 11 for each platform;
5. update version-specific review notes to describe only shipped 1.5.1 work;
6. verify the lifetime-unlock item, privacy answers, price/availability, and
   release mode; and
7. stop before the final review submission for a separate explicit approval.

## Release boundary

The signed 1.5.1 (11) iOS and macOS builds have already been uploaded and their
export-compliance answers are recorded. This design does not authorize the
final `Submit for Review` action, release, publication, or push. Any validation
error stops the metadata flow without partially submitting a platform.
