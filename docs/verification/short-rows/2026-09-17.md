# Shoulder short-row calculator — 2026-09-17

## Implementation

- KnitNote: `.worktrees/knitnote-short-rows`, branch `feature/knitnote-short-rows`, base `8fe9da8fbcc36b9dd53b6fd674cefbccc3b4efb1`.
- Calculator: `.worktrees/knitting-calculator-independent-project`, existing branch `feature/calculator-stitch-dictionary`, base `6b16af4f83b3e25a124085ea2809679564b8b522`.
- Both applications use the same `Packages/ShortRowKit` engine, SwiftUI screen, and resource bundle. Package files are byte-identical in the two worktrees. Git integration will unify these same repository paths; no cross-worktree absolute dependency is required.
- UI supports en/zh-Hant; other language selections fall back to English for this tool. App catalogs are unchanged; navigation labels also come from the package.
- Scope: flat, bottom-up, separated stockinette shoulder, neck-to-armhole, shortening wrap-and-turn rows. Start face is selectable. Not a back-neck/yoke calculator or German-short-row conversion.
- T turns require T+1 positive stitch segments; the final segment stays worked. This deliberately corrects the zero-stitch final turn caused by applying W/T to this specific schedule.
